# 第三阶段软件演示与验收

推荐用合成示例演示软件闭环，避免在公开截图中暴露实际课程内容。需要真实课程验收时，由组员在自己的已授权环境导入。

## 启动准备

源码目录执行 `npm ci`、`npm run build`、`npm start`；可运行包直接用 Python 启动，Windows 也可双击 `start-keji.cmd`。访问 `http://127.0.0.1:8765/test/hello`，确认看到 hello world。

可运行 `python tools/seed_demo.py` 填充合成课表、资料、截止和字幕，本地摘录会生成，但不会自动创建学习任务。也可完全从页面手动导入。

## 建议演示顺序

1. 看板：显示课程、课表、截止与来源；说明当前为本机单用户存储。
2. 资料：打开来源与历史版本。重复导入 `examples/stage3-course.json`，观察“未变化”而非重复新增。
3. 回放：展开导入区，选择 `examples/replay-demo.srt`，或点击“填入合成示例”。先校验和预览，再确认保存；重复导入打开同一记录。
4. 整理：选择本地原文摘录并生成。说明这是根据实际字幕选句；本次未配置真实模型，不能将它称为已验收的 AI 摘要。
5. 来源：点击章节下方时间，看到字幕原文定位及高亮。搜索一段词句，核对它来自上传文件。
6. 版本：编辑摘要后保存，再选择 v1，显示旧内容；重新生成仅追加版本。导出 JSON 查看章节、原文和时间引用。
7. 确认：勾选一个或多个知识点，确认加入学习任务。按钮变为已加入，重复请求也只有一条任务。
8. 看板：勾选学习任务，切换到已完成，刷新验证状态保留。从任务返回确认时的摘要版本。
9. 异常：导入无时间戳文本、时间逆序字幕或非字幕文件，应得到说明，不能出现成功记录。服务暂停后页面显示连接错误，恢复后可重试。
10. 版本管理：展示当前分支、基线 PR 和工作区差异；说明尚未替成员进行提交和合并。

另可展示“AI 服务设置”：说明第二阶段尚未接入运行时模型，填写课程提供的兼容地址、模型和密钥后，可先使用合成字幕测试、保存，再切换回放整理方式。没有真实凭证时展示配置入口和本地摘要即可，不用虚构厂商调用成功。完整步骤见 [AI 使用教程](AI使用教程.md)，规划衔接见 [核查记录](stage2-alignment.md)。

## 需要由组员完成的真实验收

模型配置后，用有权使用的真实字幕生成摘要，检查模型身份、额度、超时与摘要语义；依据需求书的三份字幕、每份抽查至少十个要点的方案记录判断。本地摘录及模拟服务测试不替代这一项。

本阶段没有自动音视频转写和公网账号体系，不演示未实现入口。作业辅导与备考保留原型标识。课堂汇报时间、成员贡献和课程提交情况据实填写。
