# 第三阶段变更说明

变更主题：完成第三阶段字幕回放整理与学习任务闭环

[PR #6](https://github.com/chaomianpkp/ai-course-assistant/pull/6) 已于 2026-11-18 提交，保持开放、未合并。来源为 `byz6009:feature/stage3-replay`，基线为 `stage2/public-pr`。软件实现提交为 `e02d939`，后续同一 PR 同步汇报讲稿与文档。

默认摘要来自实际字幕的本地原文摘录；OpenAI 兼容适配器可在软件内填写地址、模型与密钥，读取模型列表、测试合成摘要、保存或停用，并兼容后端环境变量。未配置时明确禁用真实 AI 入口，失败不会伪装成功或覆盖历史。音视频自动转写、作业辅导与备考生成仍待后续阶段。

同时修复 PR #2 的开放时间误判、作业详情遗漏以及 Windows 解释器与 SQLite 清理问题，补充单元/接口、模拟模型和浏览器流程测试、备份工具、启动脚本与阶段交接文档。

已逐页对照第二阶段汇报，记录设计延续和自动转写/CLI 的范围差异，提供完整 AI 使用教程。配置写入原子化、响应不回传密钥、排队任务保留提交时配置，且有对应回归测试。

验证结论见 `test-report.md`。公开内容仅包含合成示例，不包含真实课程数据库、密钥、认证信息或用户原文。本说明随第三阶段变更提交，组员人工评审、真实模型验收和课堂报告仍待进行。
