## 已完成的软件内容

- UTF-8 SRT/VTT 文件选择或粘贴、课程创建、服务器校验、预览确认、按课程和正文去重。
- 基于实际字幕的本地原文摘录；OpenAI 兼容模型接口，软件内可填 API 地址、模型和密钥，读取模型列表、测试摘要、保存/停用；兼容原环境变量方式。
- 持久化处理状态、最多五个并发任务和二十个等待名额；同一回放正在处理时复用任务；失败可显式重试。
- 字幕 ID 引用校验，由后端填写原文与开始结束时间；页面点击引用定位字幕。
- 摘要历史版本、人工编辑、版本冲突保护、导出摘要与引用。
- 用户确认所选知识点后加入学习任务；重复点击不新增；任务保留确认版本快照；看板完成状态持久化。
- 资料页关联字幕；保留已有资料、课表、截止、历史版本和教学网导入助手。
- Windows 启动器、可运行压缩包、备份工具、自动化测试与 CI 配置。

## 当前边界

用户先选择“先实现可配置接口及本地摘要，稍后接入模型”，后续要求在软件中输入网址等信息完成 API 调用。本次已补齐配置页面与完整调用流程；真实服务商凭证、调用效果和语义质量尚未验收。模型接口和浏览器调用流程通过本机模拟 HTTP 服务验证，不等于真实厂商调用通过。

字幕整理是本阶段的核心路径。音视频自动转写、OCR、公开网络检索、PDF 解析、真实作业辅导和备考生成未实现。系统仍是本机单用户版本，没有公网身份认证与用户隔离，不能直接暴露为多人服务。

按原项目甘特图“五个主模块”口径，现有软件能够演示看板、收集、回放三个模块。这个口径不等于需求书 FR01–FR08 全部细项已完成 60%；课堂验收应同步说明上述边界。
