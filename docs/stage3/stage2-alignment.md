## 本次 AI 补充交付

用户此前选择“先实现可配置接口及本地摘要，稍后接入模型”；本次进一步要求直接在软件中输入网址等信息调用 API。因此增加 `/settings/ai` 页面，填写 Base URL 或完整 Chat Completions 地址、模型 ID、API Key、超时与 JSON 模式。可选读取模型列表，使用两句合成字幕验证连接、JSON 摘要与引用，保存后立即启用。

后端保存配置并发起请求，兼容已有 `KEJI_AI_*` 环境变量。配置不回传密钥；更换地址时不能隐式复用原密钥；停用清除本机保存的密钥；配置变化只影响新任务。模型仅返回章节和字幕 ID，不能改课程数据或替学生确认。

完整操作见 [AI 使用教程](AI使用教程.md)。已用本机模拟模型服务验证协议和完整 UI 流程，没有真实服务商凭证，因此尚未验收实际模型连通性、额度或摘要语义质量。这些外部验收事项不影响配置界面和本地摘要使用。
