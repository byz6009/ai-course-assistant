## 核心案例 从字幕到学习任务

问题：原回放页仅展示三讲预设数据，点击后在 localStorage 中追加演示任务，没有实际文件解析、后台处理、来源检查与服务端保存。

实现约束先写清：字幕是不可变来源；模型只能提出内容，不能替学生确认；引用时间来自实际字幕；生成失败必须显式失败；重试和编辑不能覆盖历史；重复点击不能生成重复学习任务。

实现分为四部分：解析器负责 SRT/VTT 与边界；摘要适配器只返回章节和字幕 ID；服务负责排队、状态、引用校验与版本；页面负责核对、编辑和确认。学习任务由单独的确认接口创建，数据库唯一约束兜底。

本地摘录最初容易集中选取章节内相似片段。覆盖测试暴露这一点后，改为从每章前、中、后段分别选择代表原文，确保后段内容参与整理；仍标明为摘录，不宣称模型语义总结。

## 调试与验证记录

|发现的问题|处理方法|验证证据|
|---|---|---|
|PR #2 将开放日期计为截止|区分日期上下文，仅使用明确截止证据；保留系统到期字段|DOM 回归用例|
|作业列表无正文导致详情遗漏|合并列表与详情说明，去除相同文本|详情独有与同时存在两种用例|
|Windows 数据库文件不能删除|显式关闭 SQLite 连接、测试清理服务|Windows Python 测试|
|`python3` 不适用于所有 Windows 环境|探测解释器，允许 `KEJI_PYTHON`|当前 Windows 运行及启动器验证|
|测试环境阻止回环网络|允许测试访问 127.0.0.1，继续使用临时数据库和本地模拟服务|接口测试完整运行|
|本地摘录后段覆盖不足|章节内分段选句，保留完整可定位引用|原文及覆盖测试|
|历史版本加载期间可能误操作旧画面|增加加载状态，限制编辑和确认；浏览器测试等待实际结果|版本切换端到端测试|
|更换服务后旧密钥可能发往新地址|只允许同一规范化 Base URL 复用密钥，拒绝 HTTP 重定向|配置与重定向用例|
|模型连通测试可能误当成功验收|实际发送合成字幕，并校验 JSON、真实字幕 ID；不自动保存|模拟服务与 UI 测试|
|测试清空整个环境导致 bundled Python SSL 初始化失败|只隔离 KEJI_AI 三项变量，保留解释器运行环境|Windows 全套测试|

模型适配器使用本机 HTTP 模拟服务验证请求结构、成功 JSON、429、超时和非 JSON；这些结果不能代替真实模型验收。浏览器测试实际操作页面，独立临时数据库不与用户课程混用。
